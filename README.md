# 🏅 Certificado Oracle OCI Foundations

Este repositório tem como objetivo registrar e compartilhar meu certificado **Oracle Cloud Infrastructure (OCI) Foundations**, conquistado como parte da minha jornada de aprimoramento em computação em nuvem.

## 📘 Sobre o Certificado

A certificação **OCI Foundations** valida o conhecimento fundamental sobre:

- Conceitos essenciais de computação em nuvem  
- Arquitetura e serviços principais da Oracle Cloud  
- Governança, segurança e gerenciamento de identidade  
- Modelos de custo, suporte e boas práticas na OCI  

É uma certificação de nível inicial, ideal para quem está iniciando na carreira em cloud ou deseja compreender os fundamentos da infraestrutura Oracle.
